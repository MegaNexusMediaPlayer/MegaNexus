# Contributing

MegaNexus is developed by its author; the source code is not published in this
repository. This repository holds the releases, the Kodi repository, the
documentation and the issue tracker.

## How to help

- **Report a problem** - open a [bug report](../../issues/new?template=bug_report.md)
  (or use *HUB Settings › Help & support › Report a problem*, which sends the Kodi log).
- **Suggest a feature** - open a [feature request](../../issues/new?template=feature_request.md).
- **Test on your device** - CoreELEC, Android TV, Fire TV, Windows and others:
  what works, what is slow, with screenshots where useful (blur personal artwork).

Do not post personal profiles, account credentials, personalized provider URLs
or debug databases in issues.
